# 01 — Problem and Target Users

## 1. Problem Statement
High school and college students frequently miss homework deadlines and test preparation windows because teachers announce assignments in inconsistent ways:
- Some teachers post assignments to Google Classroom but never set an explicit due date.
- Some teachers do not use Google Classroom at all and rely on verbal announcements or whiteboards.
- Others announce deadlines inside chat channels (e.g. WhatsApp, Discord) where information quickly gets buried.

There is no single reliable source of truth for all deadlines in a class.

---

## 2. Solution: Aced
Aced is a crowdsourced deadline board designed for a specific class:
- **Zero Friction**: Students join simply with their display name and class join code (`ACED2026`). No passwords, account registration, or OAuth permissions are required.
- **Collaborative Ownership**: Any student in the class can add upcoming assignments, specify or refine deadlines, and edit notes.
- **Auditability and Revert**: Because anyone can contribute, all changes are tracked in an edit history log with editor attribution, and any erroneous modification can be undone with one tap.
- **Subject Directory**: Students can reference teachers and class Google Classroom codes in one place.

---

## 3. Target Users & Form Factor
- **Primary Users**: High school and college students accessing the board predominantly from mobile phones (minimum 375px viewport).
- **Secondary Users**: Class representatives who help audit and verify deadline dates, teacher listings, and Google Classroom codes.
